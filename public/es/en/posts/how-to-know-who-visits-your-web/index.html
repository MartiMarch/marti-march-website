¿Quién visita tu web?

Sep 12, 2025
2 min read
K8s Seo Frontend

Necesidad -> Saber quién visita mi página web Legalidad -> avisar sobre el tratamiento de datos Plausible -> Explicar que es la herramienta y que me permite hacer -> instalación en kubernetes

cloudflared login

cloudflared tunnel –url https:://pre.plausible.com

Se compran los dominios

Instalo Istio en el cluster

Ato el dominio a Istio y aplico reglas de redireccionamiento más certificado TLS

Creo un deployment para CLoudflared y le engancho el tunnel a Istio

Wuala, Istio redirige el tráfico

Comandos:

helm repo add istio https://istio-release.storage.googleapis.com/charts helm repo update helm install istio-base istio/base -n istio-system –set defaultRevision=default –create-namespace helm install istiod istio/istiod -n istio-system –wait helm install istio-ingress istio/gateway -n istio-system

apiVersion: networking.istio.io/v1alpha3
kind: Gateway
metadata:
  name: valentia-arrow-pre
  namespace: istio-system
spec:
  selector:
    istio: ingress
  servers:
  - port:
      number: 80
      name: http
      protocol: HTTP
    hosts:
    - "valentiaarrowpre.com"

apiVersion: networking.istio.io/v1alpha3
kind: VirtualService
metadata:
  name: plausible
  namespace: istio-system
spec:
  hosts:
  - "valentiaarrowpre.com"
  gateways:
  - valentia-arrow-pre
  http:
  - match:
    - uri:
        prefix: "/plausible"
    rewrite:
      uri: "/js/plausible.js"
    route:
    - destination:
        host: plausible-http.infra.svc.cluster.local
        port:
          number: 8000

Validar que redirige todo bien:

curl -v -H "Host: valentiaarrowpre.com" http://192.168.2.85/plausible
